เปิด Telegram แล้วกดส่งข้อความที่เตรียมไว้ให้ เพื่อเชื่อมต่อ:

พิมในChatbot: /start เพื่อเริ่มทำงาน (หมดอายุใน นาที)

ตั้งค่า Chat ID (ขั้นสูง / เชื่อมหลายIDพร้อมกัน)

ใส่ได้หลาย Chat ID คั่นด้วยจุลภาค ถ้าอยากแจ้งเตือนIDพร้อมกัน - ต้องกด "บันทึกการตั้งค่า" ด้านล่างเพื่อใช้ค่านี้

ช่อง "กลับปกติเมื่อ..." เว้นว่างได้ - ถ้าไม่ตั้งจะใช้ค่าเดียวกับเกณฑ์แจ้งเตือน (ไม่กันการแจ้งซ้ำตอนค่าแกว่งใกล้เส้น) ตั้งให้ห่างจากเกณฑ์แจ้งเตือนสักหน่อยเพื่อกันแจ้งถี่เกินไป
